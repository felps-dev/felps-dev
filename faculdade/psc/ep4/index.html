Sistema de Gestão de Processos Digitais (SGPD)

Protótipo navegável de média fidelidade do sistema de Help Desk corporativo da DataFlux Analytics, desenvolvido como entrega da Experiência Prática 4 da disciplina de Prototipagem de Sistemas Computacionais.

Disciplina · Prototipagem de Sistemas Computacionais EP4 · Prototipagem funcional e validação Stack · HTML + CSS + JS Felipe Correa

Telas do protótipo

Cada cartão abre uma tela navegável. As ações entre telas estão funcionando como nos fluxos planejados.
01 · AUTENTICAÇÃO

Login corporativo

Tela de entrada com autenticação via e-mail corporativo. Inclui recuperação de senha e branding DataFlux.

RNF Segurança
02 · DASHBOARD

Dashboard de chamados

Visualização e triagem dos chamados do Help Desk. Filtros por status, prioridade e SLA, com KPIs do dia.

RF02 Triagem RF05 Métricas
03 · ABERTURA

Abrir novo chamado

Formulário para o solicitante registrar um novo chamado. Categoria, prioridade, descrição livre e anexos.

RF01 Abertura CU1
04 · DETALHE

Detalhe do chamado & escalonamento

Visão completa de um chamado, com timeline, comentários e ação de escalar do nível N1 para o N2.

RF03 Escalonamento RF06 Notificações CU2
05 · BASE

Base de conhecimento

Consulta a artigos técnicos para auto-atendimento e apoio aos analistas. Busca por palavra-chave e categorias.

RF04 Base de conhecimento
Sobre este protótipo: as telas são interativas mas os dados são fictícios. O escopo cobre os principais casos de uso (CU1: abrir chamado · CU2: escalar do N1 para o N2) modelados na Experiência Prática 2 e refletem as classes definidas na Experiência Prática 3. As decisões de design seguem padrões consistentes de tipografia, paleta de cores e navegação.
